# Лавка логопеда — интернет-магазин (демо-версия)

Статический сайт без сборки: HTML + CSS + JavaScript. Маршрутизация через hash (`#/catalog`, `#/product/10234`, `#/cart`, `#/checkout`, `#/org`).

## Запуск
Откройте `index.html` в браузере или поднимите сервер: `python3 -m http.server 8000`.

## Структура
- `index.html` — шапка, подвал, точка входа
- `css/style.css` — стили, цветовые токены (фирменные синий #0046AC и оранжевый #F05800), светлая/тёмная тема
- `js/app.js` — данные товаров, каталог и фильтры, товар, корзина, избранное, формы заказа
- `assets/` — логотип и фото баннера

## Что работает
Каталог (фильтры, сортировка, поиск), карточка товара, корзина и избранное (localStorage), заказ для физлиц и заявка для организаций с валидацией.

## Что нужно подключить для запуска
- Серверная часть: приём заказов и заявок, письма, счета, загрузка файлов спецификаций, оплата. Сейчас заказ сохраняется только в браузере (демо).
- Реальные данные: товары, цены, остатки, фото товаров и категорий (сейчас заглушки), тексты «О нас», «Доставка и оплата», «Контакты».
- Отзывы и рейтинг — только на реальных данных.
